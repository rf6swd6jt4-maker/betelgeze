# SOP attachment evidence and generated titles

The attachment prompt and both publication validators accept a literal excerpt from the selected SOP step's original `source_quote` or its `instruction`. The prompt prefers the original quotation and explicitly prohibits paraphrasing, combining fields, inserting ellipses, or quoting another step. The asset-description quotation, image-to-step mapping, task type, source scope, version checks, reasons and three-per-task/twelve-per-plan limits remain mandatory. Unsupported optional suggestions are still omitted.

JavaScript and PostgreSQL normalize case and whitespace, including Unicode spaces, and reject absent, short, or oversized evidence. Neither uses fuzzy matching or a second model call.

The extraction function constructs its middle-dot separator with `chr(183)` in an ASCII-only migration. The same migration repairs only extracted-image titles exactly equal to the known corrupted autogenerated name for that image's recorded location. Custom names, descriptions, images and existing attachment links are preserved.
